
### Pokedex
This is a app called Pokedex , where user can get information about various pokemon,including the abilities they possess , type ,stat.User can search for their favourite pokemon as well.


```
Technologies used

react js
typescript
appwrite as backend

```

Features 

```
Get information about different pokemon
Search for pokemon
pagination implemented
Shows top searched pokemon based on user search.This app keeps track of user searches using appwrite.

```
